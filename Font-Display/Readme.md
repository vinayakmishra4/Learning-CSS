## 📌 Overview

**Font** and **Display** are important CSS concepts used to control how text looks and how elements are arranged on a webpage.

- 🔤 **Font Properties:** Control text appearance, size, thickness, and style.
- 🧱 **Display Property:** Controls how HTML elements behave in the layout.
- 🎯 **Goal:** Understand these properties to create attractive and user-friendly websites.

## 🔤 1. Font Properties

Font properties control the appearance and readability of text on a website. Choosing the right typography helps establish visual hierarchy and improves the user experience.

### ✨ Important Font Properties

| Property | Description |
|---|---|
| `font-family` | Defines the typeface used for text. |
| `font-size` | Sets the size of the text. |
| `font-weight` | Controls the thickness of characters. |
| `font-style` | Defines normal, italic, or oblique text. |
| `font-variant` | Controls variants such as small capital letters. |
| `line-height` | Sets the height of a line of text. |
| `letter-spacing` | Controls the spacing between letters. |
| `word-spacing` | Controls the spacing between words. |

### 🎯 Why Font Properties Matter

- Improve text readability.
- Create clear headings and content hierarchy.
- Establish a consistent website design.
- Enhance branding and visual appeal.
- Make content more comfortable to read.

## 🧱 2. Display Property

The `display` property determines how an HTML element participates in the layout of a webpage.

It affects whether elements appear on separate lines, remain alongside other elements, or use a flexible or grid-based layout.

### 📦 Types of Display

| Display Value | Description |
|---|---|
| `block` | Starts on a new line and generally occupies the available width. |
| `inline` | Flows within a line and takes up the space its content requires. |
| `inline-block` | Flows inline while allowing width and height to be set. |
| `flex` | Creates a flexible layout for arranging and aligning elements. |
| `grid` | Creates a two-dimensional layout using rows and columns. |
| `none` | Hides the element and removes its layout space. |
| `contents` | Removes the element's own layout box while retaining its children in the layout. |
| `list-item` | Makes an element behave like a list item. |

### 🎯 Why the Display Property Matters

- Organizes elements on a webpage.
- Controls how elements flow and occupy space.
- Helps create navigation bars and card layouts.
- Makes alignment and spacing easier.
- Supports responsive and modern web design.

---

## ⚖️ 3. Font vs Display

| Font Properties | Display Property |
|---|---|
| Control text appearance. | Controls element layout behavior. |
| Improve typography and readability. | Organizes elements on a webpage. |
| Apply to text styling. | Applies to layout and presentation. |
| Examples: `font-size`, `font-weight`. | Examples: `block`, `flex`, `grid`. |

## 💡 4. Best Practices

- ✅ Choose readable fonts and appropriate font sizes.
- ✅ Maintain consistent typography throughout the website.
- ✅ Use headings to establish a clear content hierarchy.
- ✅ Prefer `flex` for one-dimensional layouts.
- ✅ Prefer `grid` for two-dimensional layouts.
- ✅ Use `inline-block` when inline flow and explicit dimensions are needed.
- ✅ Use `display: none` when an element should be hidden from layout.
- ✅ Test layouts on different screen sizes.
