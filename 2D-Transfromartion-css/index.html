Transforms, transitions and animations

Transforms

Transforms rotate, move, skew or scale an element. The dashed outline marks where each box started.

2D transform methods

transform-origin

The origin is the point an element transforms around. The default is the center.

3D transform methods

3D transforms need depth, so the stage sets perspective: 320px.

Transitions

Transitions change a property value smoothly over a set time. Hover over a bar, or focus it with the Tab key, to trigger the change.

Animations

Animations give more control than transitions. A @keyframes rule describes the styles, and the animation properties say how to play them.

@keyframes harry { from { width: 20px; } to { width: 200px; } }
