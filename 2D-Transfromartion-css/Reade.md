## 📖 Overview

This chapter focuses on three important CSS concepts: **Transforms, Transitions, and Animations**.

These features help make web pages more interactive, dynamic, and visually appealing without requiring JavaScript.

This project demonstrates different transformation techniques, smooth property transitions, and keyframe-based animations through interactive visual examples.

---

## 🔹 01. CSS Transforms

CSS Transforms allow us to modify the position, size, angle, and shape of HTML elements.

### Concepts Covered

**2D Transformations**
- `translate()` – Moves elements along the X and Y axes.
- `rotate()` – Rotates elements around a fixed point.
- `scaleX()` – Changes the horizontal size.
- `scaleY()` – Changes the vertical size.
- `scale()` – Increases or decreases the overall size.
- `skew()` – Tilts elements along the axes.
- `matrix()` – Combines multiple 2D transformations.

**Transform Origin**
- Understand how the transformation starting point affects rotation.
- Explore different origins, including top-left and bottom-right.
- Learn how changing the origin changes the visual result.

**3D Transformations**
- `rotateX()` – Rotation around the X-axis.
- `rotateY()` – Rotation around the Y-axis.
- `rotateZ()` – Rotation around the Z-axis.

**Perspective**
- Understand how perspective creates depth in 3D transformations.

## 🔹 02. CSS Transitions

CSS Transitions allow property values to change smoothly over a specified duration.

### Concepts Covered

- `transition-property` – Defines which property will change.
- `transition-duration` – Controls the time taken for the transition.
- `transition-timing-function` – Controls the speed and movement curve.
- `transition-delay` – Defines the waiting time before the transition begins.

### Transition Techniques

- Using individual transition properties (Longhand).
- Using the transition shorthand property.
- Applying transitions to multiple CSS properties.
- Creating smooth hover effects.
- Triggering transitions using keyboard focus.

**Key Learning:** Transitions make changes between CSS states smooth and visually engaging.

---

## 🔹 03. CSS Animations

CSS Animations provide greater control over how elements change their appearance over time.

### Concepts Covered

- Understanding the `@keyframes` rule.
- Defining animation starting and ending states.
- Animating multiple CSS properties.
- Controlling animation duration and speed.
- Creating continuous and alternate animations.

### Animation Properties

- `animation-name` – Defines the animation name.
- `animation-duration` – Sets the animation duration.
- `animation-timing-function` – Controls the animation speed curve.
- `animation-delay` – Sets the starting delay.
- `animation-iteration-count` – Defines the number of repetitions.
- `animation-direction` – Controls the animation direction.

### Animation Techniques

- Using individual animation properties (Longhand).
- Using animation shorthand.
- Creating infinite animations.
- Applying reverse and alternate animation directions.

---

## 🔹 04. Percentage Values in Animations

Percentage values inside `@keyframes` define different stages of an animation.

- **0%** – Starting stage.
- **50%** – Intermediate stage.
- **100%** – Final stage.

### Concepts Covered

- Defining multiple animation stages.
- Changing multiple properties at different stages.
- Creating smooth visual transformations.
- Controlling how an element changes throughout an animation.
