CSS Grid & Media Queries

This page demonstrates a grid container, grid columns, rows, gaps, items that span columns, and responsive styles for different screen sizes.

Grid Container

display: grid; turns this section into a CSS Grid container. Its direct children become grid items.

Columns

grid-template-columns sets the width of the grid columns.

Rows

grid-template-rows sets the height of the grid rows.

Column Gap

grid-column-gap controls the space between columns.

Row Gap

grid-row-gap controls the space between rows.

Grid Item Spanning

This card spans two columns using grid-column: 1 / span 2;.
