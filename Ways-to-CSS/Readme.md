## 📚 Three Types of CSS

### 1. Inline CSS

Inline CSS is applied directly to an individual HTML element through its style attribute.

**Advantages**
- Quick and simple to apply.
- Useful for styling a specific element.

**Disadvantages**
- Difficult to maintain across multiple elements.
- Mixes styling with HTML content.

### 2. Internal CSS

Internal CSS is written inside a style element in the head section of an HTML document.

**Advantages**
- Keeps styles together within one HTML file.
- Suitable for styling a single webpage.

**Disadvantages**
- Not easily reusable across multiple webpages.
- Can make HTML documents harder to maintain when styles grow.

### 3. External CSS

External CSS is stored in a separate CSS file and connected to an HTML document using a stylesheet link.

**Advantages**
- Separates presentation from HTML structure.
- Allows styles to be reused across multiple webpages.
- Makes styling easier to organize and maintain.

**Disadvantages**
- Requires the stylesheet path to be correct.
- Styling may not load if the external file is unavailable.

## 📊 Comparison of CSS Types

| Type | Location | Best Use |
|---|---|---|
| Inline CSS | Inside an HTML element | Styling a specific element |
| Internal CSS | Within the HTML document | Styling a single webpage |
| External CSS | In a separate CSS file | Styling multiple webpages |

## 🎯 CSS Selectors

CSS selectors identify the HTML elements to which styles should apply.

- **Element selector:** Targets elements by their HTML tag name.
- **Class selector:** Targets elements assigned a particular class.
- **ID selector:** Targets an element with a specific ID.

## 💡 Important Notes

- Inline, internal, and external CSS are the three common ways to apply CSS.
- CSS specificity and the cascade determine which styles take precedence when declarations conflict.
- External CSS is generally recommended for larger projects because it improves organization and maintainability.
- HTML class names and IDs must correspond to the selectors used in the stylesheet.
