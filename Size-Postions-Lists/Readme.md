## 📚 Topics Covered

### 1. 📏 Size — CSS Units

CSS units define the size of elements, text, margins, padding, and other properties.

**Types of CSS Units**

- **Absolute Units:** `px`, `cm`, `mm`, `in`, `pt`, `pc`
- **Relative Units:** `%`, `em`, `rem`, `vw`, `vh`, `vmin`, `vmax`, `ch`, `ex`

📖 **Documentation:** [CSS Values and Units — MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Values_and_units)

### 2. 📍 Positions — CSS Position Property

The `position` property controls how an element is placed on a webpage.

**Types of Positions**

- `static` — Default positioning
- `relative` — Relative to its normal position
- `absolute` — Relative to its containing block
- `fixed` — Relative to the viewport
- `sticky` — Sticks during scrolling

**Related Properties:** `top`, `right`, `bottom`, `left`, `z-index`

📖 **Documentation:** [CSS Position — MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/position)

🔗 **My Code:** [fpostion.html](https://github.com/vinayakmishra4/Learning-CSS/blob/main/Size-Postions-Lists/fpostion.html)

---

### 3. 📋 Lists — CSS List Properties

CSS list properties customize list markers and their positions.

**Types of HTML Lists**

- **Ordered List (`ol`)** — Numbered or ordered items
- **Unordered List (`ul`)** — Bulleted items
- **Description List (`dl`)** — Terms and descriptions

**Important CSS Properties**

- `list-style-type`
- `list-style-position`
- `list-style-image`
- `list-style`

📖 **Documentation:** [CSS List Properties — MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/list-style)
