## 🌐 What is CSS?

**CSS (Cascading Style Sheets)** is a stylesheet language used to control the **look and feel of web pages**.

With CSS, we can change:

- 🎨 Colors
- ✍️ Fonts and text
- 📐 Layouts
- 📏 Spacing
- 🖼️ Backgrounds
- 📱 Responsive designs
- ✨ Overall appearance

Think of it like this:

```text
HTML → Structure 🏗️
CSS  → Style 🎨
JavaScript → Behavior ⚡
```

---

## 📚 What I'm Learning

This introduction covers the basic connection between **HTML and CSS**.

### HTML

HTML provides the structure and content of the webpage.

```html
<h1>My First CSS Website</h1>
<p>This is my first website using CSS.</p>
```

### CSS

CSS is used to style those HTML elements.

```css
main {
    text-align: center;
    color: #ff0000;
}
```

---

## 🧠 Key CSS Concepts

| Concept | Purpose |
|---|---|
| 🎯 Selectors | Select HTML elements |
| 🎨 Colors | Change text/background colors |
| 📝 Text Styling | Customize fonts and text |
| 📦 Box Model | Control spacing and dimensions |
| 📐 Layout | Arrange elements on a page |
| 📱 Responsive Design | Adapt pages to different screens |
